# Design System — Spectral Emerald

Documentação visual do Spectral AI.

## Base visual

- Base clara: branco e off-whites esverdeados.
- Ação: `emerald-700` (#047857); foco: `emerald-600` (#059669).
- Texto: #0B1F17; apoio: #5B6B63; bordas: #E3EBE6; superfícies: #F4F8F6.
- Radius base: `0.625rem`.
- Dark mode: tema `system`, `light` e `dark` em Configurações → Geral → Aparência.

## Tipografia

- Geist Sans para interface.
- Geist Mono para dados, números e código.

## Componentes

`button`, `card`, `input`, `label`, `badge`, `separator`, `skeleton`, `avatar`, `dropdown-menu` e `tooltip`.

## Implementação

- Tokens: `app/globals.css`
- Referência visual: `/styleguide`
- Biblioteca: shadcn/ui com Base UI e CSS variables
